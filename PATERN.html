Pattern 1

Two Pointers

Opposite ends or fast/slow tracking on ordered data.

💡 Layman Analogy: "Two friends walking from opposite ends of a street towards each other to meet at a house whose address numbers sum up to a target."

By maintaining two index markers moving towards each other (or together), you instantly eliminate unnecessary pair comparisons. In sorted arrays, if your current sum is too small, advance the left pointer; if it's too large, move the right pointer inward.

🔍 When to Use & Key Triggers

  • •Target Sum Pairs in Sorted Array: Two Sum II, 3Sum, 4Sum.
  • •In-Place Element Swapping/Filtering: Remove Duplicates, Move Zeroes.
  • •Boundary Containers: Trapping Rain Water, Container With Most Water.

⚠️ Common Traps & Tweaks

  • 1.Unsorted Input: If original indices are required and array isn't sorted, sort will lose original indices! Use Hash Map instead.
  • 2.Duplicate Triplets in 3Sum: Always advance pointers past identical values with while(arr[L] == arr[L+1]) L++.
int twoPointersOpposite(vector<int>& arr, int target) {
    int left = 0, right = arr.size() - 1;
    while (left < right) {
        int sum = arr[left] + arr[right];
        if (sum == target) return 1; // Pair found
        else if (sum < target) left++; // Need larger value
        else right--; // Need smaller value
    }
    return 0;
}
Pattern 2

Sliding Window

Maintain continuous window [Left...Right] over arrays or strings.

💡 Layman Analogy: "Sliding a magnifying glass frame across a strip of film to find the longest sub-section without any repeated colors."

Instead of recalculating the sum/state of every subarray from scratch ($O(K)$ or $O(N)$), you incrementally add the new incoming item at `Right` and subtract the outgoing item at `Left` in $O(1)$ time.

🔍 When to Use & Key Triggers

  • •Fixed Size K: Max sum of subarray of size K.
  • •Variable Max/Min Length: Longest Substring Without Repeating Characters, Min Size Subarray Sum.
  • •Character Frequency Matches: Anagrams in a string.

⚠️ Common Traps & Tweaks

  • 1.Negative Numbers Break Sliding Window: Adding elements no longer guarantees monotonic sum growth! Switch to Prefix Sum + Hash Map.
  • 2."Exactly K" Trick: Compute `atMost(K) - atMost(K - 1)`.
int maxSubarraySumFixed(vector<int>& arr, int k) {
    int currentSum = 0;
    for (int i = 0; i < k; i++) currentSum += arr[i];

    int maxSum = currentSum;
    for (int i = k; i < arr.size(); i++) {
        currentSum += arr[i] - arr[i - k]; // Slide window
        maxSum = max(maxSum, currentSum);
    }
    return maxSum;
}
Pattern 3

Kadane's Algorithm

Local dynamic programming greedy choice for maximum contiguous sum.

💡 Layman Analogy: "Riding a winning streak in a game. If your past score drops below zero, dump your baggage and start fresh with today's game!"

At each index `i`, ask: "Should I extend my existing continuous sum, or dump the past prefix and start fresh at `arr[i]`?"
Core Formula: currentSum = max(arr[i], currentSum + arr[i]).

🔍 When to Use & Key Triggers

  • •Max Subarray Sum: Contiguous subarray with largest sum.
  • •Circular Subarray Sum: Max sum when wrapping around end to start.
  • •Max Product Subarray: Tracking min and max running products simultaneously.

⚠️ Common Traps & Tweaks

  • 1.All Negative Numbers: Initializing sum to `0` returns `0` incorrectly. Initialize maxSum = arr[0]!
  • 2.Circular Wrap Formula: max(Kadane, TotalSum - MinKadane).
int maxSubArray(vector<int>& nums) {
    int currentSum = nums[0], maxSum = nums[0];
    for (size_t i = 1; i < nums.size(); i++) {
        currentSum = max(nums[i], currentSum + nums[i]);
        maxSum = max(maxSum, currentSum);
    }
    return maxSum;
}
Pattern 4

Prefix Sum

Precompute cumulative totals for instant $O(1)$ range queries.

💡 Layman Analogy: "A running total on a receipt. To find how much items #3 to #7 cost, subtract the total at item #2 from the total at item #7!"

By storing cumulative totals where P[i] = sum(arr[0...i-1]), any contiguous sub-range sum from index $L$ to $R$ is calculated instantly as P[R+1] - P[L]. Combined with a Hash Map, it solves negative array subarray target problems in $O(N)$ time.

🔍 When to Use & Key Triggers

  • •Instant Range Queries: Multiple range sum requests on immutable arrays.
  • •Subarray Sum Equals K (With Negatives): Finding continuous subarrays summing to K.
  • •Divisible Subarrays: Finding subarray sums divisible by K using mod math.

⚠️ Common Traps & Tweaks

  • 1.Missing Map Base Case: Always seed Hash Map with map[0] = 1 to count subarrays starting from index 0!
  • 2.C++ Negative Modulo: Normalize remainder: rem = ((sum % k) + k) % k.
class NumArray {
    vector<int> prefix;
public:
    NumArray(vector<int>& nums) {
        prefix.resize(nums.size() + 1, 0);
        for (size_t i = 0; i < nums.size(); i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
    }
    int sumRange(int L, int R) {
        return prefix[R + 1] - prefix[L];
    }
};
Pattern 5

Merge Intervals

Combine, insert, or detect overlapping start and end time ranges.

💡 Layman Analogy: "Combining overlapping calendar meetings. If Meeting A is 1:00–3:00 PM and Meeting B is 2:00–4:00 PM, merge them into one blocked period: 1:00–4:00 PM!"

Sort intervals by their start times [start, end]. Iterate through intervals and check if the current interval's start time is $\le$ the previous interval's end time. If true, they overlap—merge them by updating the end time to max(prev.end, curr.end).

🔍 When to Use & Key Triggers

  • •Overlapping Time Schedules: Merge Intervals, Insert Interval.
  • •Meeting Room Capacity: Meeting Rooms II (Minimum rooms required using min-heap).
  • •Range Intersections: Interval List Intersections.

⚠️ Common Traps & Tweaks

  • 1.Forgetting Initial Sort: Intervals are often given unsorted! Always sort by start time first: sort(intervals.begin(), intervals.end()).
  • 2.Boundary Touching: Check if `[1, 3]` and `[3, 5]` are considered overlapping in the question (`start <= prevEnd` vs `start < prevEnd`).
vector<vector<int>> merge(vector<vector<int>>& intervals) {
    if (intervals.empty()) return {};
    // CRITICAL STEP: Sort intervals by start time
    sort(intervals.begin(), intervals.end());

    vector<vector<int>> merged;
    merged.push_back(intervals[0]);

    for (size_t i = 1; i < intervals.size(); i++) {
        auto& last = merged.back();
        // Check if current interval overlaps with last merged interval
        if (intervals[i][0] <= last[1]) {
            last[1] = max(last[1], intervals[i][1]); // Merge
        } else {
            merged.push_back(intervals[i]); // Push distinct interval
        }
    }
    return merged;
}
