Recommended Pattern: Two Pointers Time: O(N) | Space: O(1)

Use two pointers starting at opposite ends (left=0, right=n-1). Move pointers inward based on whether current sum is smaller or larger than target.

⚠️ Tweak Alert: If duplicate tuples are disallowed, advance pointers past matching adjacent elements after finding a valid match.
Pattern 1

Two Pointers

Opposite ends, fast/slow tracking, or inward traversal on sequential data.

Mind Map: "Use two index markers moving towards or alongside each other to search, compare, or modify linear structures in O(N) time without extra memory."

The Two Pointers pattern utilizes structural order (usually sorted arrays or monotonic sequences) to discard large search spaces without checking every combination. By moving pointers based on strict inequality logic, nested loop operations drop from $O(N^2)$ down to $O(N)$.

◆ Question Taxonomies & Triggers

  • •
    Target Pair / Triplet Finding: Given a sorted array, find two/three numbers that sum to target (e.g., Two Sum II, 3Sum, 4Sum).
  • •
    In-Place Modification: Fast/Slow pointers to remove duplicates or shift zeroes in $O(1)$ space (e.g., Remove Duplicates from Sorted Array).
  • •
    Palindrome & Reversal: Check if string is palindrome or reverse elements by swapping inward.
  • •
    Container Boundaries: Trapping Rain Water, Container With Most Water using boundary pointers.

⚠️ When & Where Tweaks Exist

  • 1.
    Unsorted Array with Index Preservation: If original indices must be returned and array cannot be sorted, standard two pointers fails! Tweak: Use Hash Map ($O(N)$ space) or store {val, index} pairs before sorting.
  • 2.
    Skipping Duplicates in Triplet Search: To avoid duplicate triplets in 3Sum, sort array first, then skip identical adjacent values using while(arr[i] == arr[i-1]) and advance inner pointers past matching elements.
  • 3.
    Fast & Slow Cycle Detection: In Linked Lists or functional loops, move slow by 1 step and fast by 2 steps (Floyd's algorithm).
int twoPointersOpposite(vector<int>& arr, int target) {
    // Array MUST be sorted for target sum search
    int left = 0;
    int right = arr.size() - 1;

    while (left < right) {
        int currentSum = arr[left] + arr[right];
        if (currentSum == target) {
            return 1; // Found pair
        } else if (currentSum < target) {
            left++; // Need larger sum, move left pointer right
        } else {
            right--; // Need smaller sum, move right pointer left
        }
    }
    return 0; // Not found
}
Pattern 2

Sliding Window

Maintain a dynamic contiguous sub-segment [L, R] over an array or string.

Mind Map: "Expand the right pointer to include elements; shrink the left pointer when conditions break. Computes contiguous segment properties in O(N)."

Sliding Window maintains running metrics over a continuous window. Instead of recalculating sub-segment properties from scratch (which takes $O(K)$ or $O(N)$ per element), it updates metrics incrementally by adding the incoming element at right and removing the outgoing element at left.

◆ Question Taxonomies & Triggers

  • •
    Fixed Window Size K: Maximum/minimum sum or average of contiguous subarray of exact size $K$.
  • •
    Variable Window - Max Length: Find longest contiguous substring/subarray satisfying condition (e.g., Longest Substring Without Repeating Characters).
  • •
    Variable Window - Min Length: Find shortest contiguous subarray whose sum is $\ge$ target (e.g., Minimum Size Subarray Sum).
  • •
    String Anagrams & Frequency Matching: Permutation in String, Find All Anagrams using frequency maps.

⚠️ When & Where Tweaks Exist

  • 1.
    Arrays with Negative Numbers: Standard sliding window breaks completely if the array contains negative numbers because adding an element no longer guarantees monotonic sum growth! Tweak: Switch to Prefix Sum + Hash Map or Monotonic Queue.
  • 2.
    "At Most K" trick for "Exactly K": To count subarrays with Exactly K distinct elements, calculate: atMost(K) - atMost(K - 1).
  • 3.
    Min Window vs Max Window Shrink Condition: Max Length problems shrink with while(invalid); Min Length problems shrink with while(valid) to minimize size.
int maxSubarraySumFixed(vector<int>& arr, int k) {
    if (arr.size() < k) return 0;

    int currentSum = 0;
    for (int i = 0; i < k; i++) {
        currentSum += arr[i]; // First window
    }

    int maxSum = currentSum;
    for (int i = k; i < arr.size(); i++) {
        currentSum += arr[i] - arr[i - k]; // Slide window: Add right, remove left
        maxSum = max(maxSum, currentSum);
    }
    return maxSum;
}
Pattern 3

Kadane's Algorithm

Local dynamic programming choice for maximum contiguous subarray sum.

Mind Map: "Maintain running sum; if running sum drops below zero, reset to current element. A negative prefix pulls down future subarray sums."

Kadane's algorithm makes a greedy choice at every element $i$: Should we add $arr[i]$ to the existing running subarray, or dump the past prefix and start a new subarray fresh at $arr[i]$? Formula: currentSum = max(arr[i], currentSum + arr[i]).

◆ Question Taxonomies & Triggers

  • •
    Classic Maximum Subarray Sum: Find contiguous subarray with largest sum in $O(N)$ time and $O(1)$ space.
  • •
    Maximum Circular Subarray Sum: Subarray can wrap around end of array to start.
  • •
    Maximum Product Subarray: Contiguous subarray with largest product (requires min/max product tracking).
  • •
    Subarray Index Retrieval: Return actual starting and ending indices of the max subarray.

⚠️ When & Where Tweaks Exist

  • 1.
    All Negative Numbers Edge Case: If initialized to 0, Kadane returns 0 for all negative arrays. Tweak: Initialize currentSum = arr[0] and maxSum = arr[0].
  • 2.
    Circular Array Wrapping Formula: Wrapped Max = TotalSum - MinKadaneSubarraySum. Final answer = max(StandardKadane, TotalSum - MinKadane). If all numbers negative, return StandardKadane.
  • 3.
    Max Product Subarray Tweak: Multiplying two negatives creates a positive! Tweak: Track BOTH maxProd and minProd, and swap them when encountering a negative number.
int maxSubArray(vector<int>& nums) {
    if (nums.empty()) return 0;

    int currentSum = nums[0];
    int maxSum = nums[0];

    for (size_t i = 1; i < nums.size(); i++) {
        // Decide: Add to existing sequence or start new from nums[i]?
        currentSum = max(nums[i], currentSum + nums[i]);
        maxSum = max(maxSum, currentSum);
    }
    return maxSum;
}
Pattern 4

Prefix Sum

Precompute cumulative values to perform instantaneous O(1) range queries.

Mind Map: "Store cumulative sum array where P[i] = sum(arr[0...i-1]). Any contiguous range sum arr[L...R] equals P[R+1] - P[L]."

Prefix Sum shifts query time complexity from $O(N)$ down to $O(1)$ by doing $O(N)$ precomputation. When combined with Hash Maps, it allows finding non-contiguous history matches (such as subarrays summing to $K$ or divisible by $K$) even when array contains negative numbers.

◆ Question Taxonomies & Triggers

  • •
    Range Sum Queries (Immutable Array): Answer frequent range sum requests from index $L$ to $R$ in $O(1)$ time.
  • •
    Subarray Sum Equals K: Find number of continuous subarrays that sum to $K$ (works with negative elements).
  • •
    Subarrays Divisible by K: Count subarrays where total sum is divisible by $K$ using remainder maps.
  • •
    2D Range Sum Matrix: Sub-rectangle sum queries on static grids via inclusion-exclusion.

⚠️ When & Where Tweaks Exist

  • 1.
    Map Initializer Tweak (Map[0] = 1): In "Subarray Sum = K", always seed Hash Map with map[0] = 1! This handles valid subarrays that begin exactly at index 0.
  • 2.
    Negative Modulo Arithmetic Tweak: In C++, -2 % 5 = -2. In "Divisible by K" problems, normalize remainders: rem = ((sum % k) + k) % k to prevent missing map key lookups.
  • 3.
    2D Grid Inclusion-Exclusion Formula: Query $(r1,c1)$ to $(r2,c2)$: P[r2][c2] - P[r1-1][c2] - P[r2][c1-1] + P[r1-1][c1-1].
class NumArray {
    vector<int> prefix;
public:
    NumArray(vector<int>& nums) {
        prefix.resize(nums.size() + 1, 0);
        for (size_t i = 0; i < nums.size(); i++) {
            prefix[i + 1] = prefix[i] + nums[i]; // Build cumulative sum
        }
    }
    
    int sumRange(int left, int right) {
        // Query sum from left to right inclusive in O(1)
        return prefix[right + 1] - prefix[left];
    }
};
